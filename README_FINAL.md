## Mathematical scope

The revised title is "Logical Slab Access and Local Processing with
Three-Dimensional Layer Codes at Optimal Distance". The paper corrects
the Z-sector gauging argument, treats arbitrary defective resources as
channels/error spaces, distinguishes static and circuit distances, defines
the protected transfer quotient, and supplies supporting proofs and exact
factory conventions. It reconciles all displayed numerical counts with the
recorded scheduler and distinguishes solver optima from unresolved bounds.

The architecture theorem is explicitly conditional on Assumption IV.1.
Uniform adaptive detector incidence, open-boundary composition, spectator
propagation, and decoder/resource witness guarantees are not established
by finite checks. The revision does not claim those missing uniform proofs
have been completed. Earlier text retained in research_records may make
stronger claims; the revised main manuscript defines this edition's scope.

## Build

Install a TeX distribution with REVTeX 4.2, Latin Modern, amsmath, amssymb,
amsthm, booktabs, graphicx, microtype, bm, and hyperref. In this directory run:

    pdflatex -interaction=nonstopmode -halt-on-error manuscript.tex
    pdflatex -interaction=nonstopmode -halt-on-error manuscript.tex
    pdflatex -interaction=nonstopmode -halt-on-error manuscript.tex

This creates the 20-page manuscript body. To add the clickable contents
page and preserve all internal destinations, install Python packages
PyMuPDF and reportlab and run:

    python assemble_final.py

The complete 21-page PDF appears under build/. Existing vector figures
are included; regeneration is not needed to build the paper. The revised
schematic is generated by make_intuition_figure.py with Matplotlib and TeX.

## Checks and records

revision_checks/IRIS_independent_checks.py requires NumPy and reconstructs
the small lattice instances independently, checks ranks, stabilizer lifts,
slab commutation, teleportation identities, and numerical arithmetic.
factory_map_audit.py checks the finite factory phase conventions.
The reference script and records are distinct from an arbitrary-size proof.
No new Monte Carlo samples were generated for this revision, and the full
simulation campaigns have not been independently rerun.

Appendix F identifies the simulation, inference, and solver records behind
the tables and plots. research_records/ preserves the available author
package, including older manuscript text, supplement, code, data, seeds,
requirements, and environment records. This is a local research archive;
no public deposition or DOI is claimed. Dates or environments within the
archived records refer to their original runs.

SHA256_MANIFEST.json records every packaged file except the manifest itself.
